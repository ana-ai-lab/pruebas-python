# 🎲 Juego de Adivinanza en Python

Este es un juego interactivo de consola desarrollado en Python como parte de mi ruta de aprendizaje de lógica de programación desde cero.

## 📝 Descripción
El programa reta al usuario a adivinar un número secreto. Tras cada intento, el sistema proporciona pistas indicando si el número buscado es mayor o menor, manteniendo un contador con un límite estricto de intentos.

## 🛠️ Conceptos aplicados
- **Variables y tipos de datos:** Almacenamiento y conversión de datos con `int()`.
- **Estructuras condicionales:** Toma de decisiones mediante `if`, `elif` y `else`.
- **Bucles de repetición:** Control del flujo con `while` mientras queden intentos disponibles.
- **Herramientas del oficio:** Control de versiones con Git y subida a GitHub desde VS Code.
